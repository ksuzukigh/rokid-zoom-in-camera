# Rokid ZOOM IN CAMERA

Rokid AI Glasses RV101の広角カメラを、見たい範囲へ寄せて使うズームカメラです。

遠くの文字や小さな物をその場で拡大して確認し、見えている倍率のまま写真や無音動画として残せます。撮影後は、スマートフォンのHi Rokidへ取り込んで利用できます。

**現在のバージョン: 1.0.1**

[Rokid ZOOM IN CAMERAの最新版をダウンロード](https://github.com/ksuzukigh/rokid-zoom-in-camera/releases/latest/download/Rokid-ZOOM-IN-CAMERA.zip)

> Rokid本体の単色表示に近づけた再現画像です。実際の見え方は周囲の明るさや装着位置によって異なります。

ズームはカメラ映像の中央を切り出して拡大するデジタルズームです。倍率を上げても保存する画像のピクセル数は変わりませんが、高倍率ほど細部は粗くなります。

## できること

- カメラ映像を1.0〜4.0倍の5段階で拡大
- 表示の縦横比を保ったまま、RV101の画面いっぱいに表示
- 右テンプルのボタンを1回押して写真を撮影
- 右テンプルのボタンを長押しして、音声の入らない動画を撮影
- 現在の倍率、電池残量、録画時間を画面内に表示
- 撮った写真と動画をHi Rokidへ取り込み、スマートフォンで利用
- 通信、クラウド、位置情報、マイクを使わずに動作

## 使い方

1. Rokidのアプリ一覧から「Rokid ZOOM IN CAMERA」を開きます。
2. 画面中央の十字を、見たい物へ合わせます。
3. 左右へスワイプして倍率を選びます。
4. 見るだけならそのまま、残したい場合は写真または動画を撮ります。
5. 撮影後、スマートフォンのHi Rokidへ取り込みます。

| したいこと | 操作 | 画面の動き |
|---|---|---|
| 倍率を上げる | 右へスワイプ | 1.0 → 1.5 → 2.0 → 3.0 → 4.0倍 |
| 倍率を下げる | 左へスワイプ | 4.0 → 3.0 → 2.0 → 1.5 → 1.0倍 |
| 写真を撮る | 右テンプルのボタンを1回押す | 撮影後に「保存しました」と表示 |
| 動画を始める | 右テンプルのボタンを長押し | 指を離しても録画を継続 |
| 動画を終える | 録画中に右テンプルのボタンを1回押す | 録画を終了して保存 |

録画中は倍率を変更できません。録画を始める前に倍率を選んでください。

## 動画を撮る

録画を始めると、右上に「録画中」と経過時間が表示されます。指を離しても録画は続きます。終了するときだけ、右テンプルのボタンをもう一度押します。

<p align="center"><img src="docs/images/recording-hud-green.png" width="360" alt="Rokid ZOOM IN CAMERAで4.0倍の動画を録画している画面"></p>

> Rokid本体の単色表示に近づけた再現画像です。実際の見え方は周囲の明るさや装着位置によって異なります。

動画に音声は入りません。マイクの許可も使用しません。

## 電池残量が画面で分かる

画面右上にRokid本体の電池残量を常時表示します。色だけに頼らず、残量が少ないときは文字でも知らせます。

| 状態 | 表示 |
|---|---|
| 通常 | `電池 68%`のように残量を表示 |
| 20%以下 | `電池少 20%`のように表示 |
| 10%以下 | `要充電 10%`のように表示 |
| 充電中 | `充電中 68%`のように表示 |

長時間の録画は電池を多く使います。電池残量と本体の温度を確認しながら使用してください。

## Hi Rokidへ取り込む

撮った写真と動画は、スマートフォンの専用アプリ「Hi Rokid」から取り込んで利用します。Rokid本体の保存フォルダを直接操作する必要はありません。

1. スマートフォンでHi Rokidを開き、Rokidと接続します。
2. Hi RokidのGallery（アルバム）を開きます。
3. Rokid内の写真または動画を選び、スマートフォンへ取り込みます。
4. 取り込み後は、スマートフォンで確認、保存、共有できます。

Hi Rokidの画面名は、アプリのバージョンや表示言語によって異なる場合があります。

| 項目 | 保存内容 |
|---|---|
| 写真 | 4032×3024ピクセルのJPEG |
| 動画 | 1920×1080ピクセルのMP4 |
| 動画方式 | H.264、約30fps、音声なし |

<details>
<summary>写真・動画の詳しい仕様</summary>

Rokid ZOOM IN CAMERAは、Hi Rokidから見つけられるよう、写真と動画をRokid本体の標準メディアとして登録します。内部の保存先は`DCIM/Camera`ですが、通常の利用でこのフォルダを直接操作する必要はありません。

ファイル名には撮影日時と倍率が入ります。

- 写真の例：`RokidZoomIn_20260817_123456_2.0x.jpg`
- 動画の例：`RokidZoomIn_20260817_123456_2.0x.mp4`

撮影のたびに解像度と動画設定をアプリ自身で指定するため、Hi Rokidの画質設定とは基本的に連動しません。

| 項目 | Rokid AI Glasses RV101での仕様 |
|---|---|
| 写真 | 4032×3024ピクセル（約12.2メガピクセル）のJPEG |
| 動画 | 1920×1080ピクセル（フルHD）のMP4 |
| 動画方式 | H.264、音声なし |
| フレームレート | 30fps指定（実機でも約30fps） |
| 動画ビットレート | 10Mbps指定 |

写真はRV101が出力できる最大のJPEGサイズを自動で選びます。Hi Rokidへ取り込んだあとの表示、圧縮、透かしの有無は別の処理です。

</details>

## Rokid Controlと一緒に使う

[Rokid Control](https://github.com/ksuzukigh/rokid-mac-control)をMacで開いている場合、Rokid ZOOM IN CAMERAを起動すると、Macの表示も拡大したフルカラーの撮影画面へ自動で切り替わります。

倍率、操作案内、電池残量、録画時間をMac側でも確認できます。Rokid ZOOM IN CAMERAを閉じると、Rokid Controlで選んでいた「ライブ映像」または「背景なし（省電力）」へ自動で戻るため、Rokid Controlを開き直す必要はありません。

Rokid Controlは撮影に必須ではありません。Rokid単体でも、表示、倍率変更、写真、動画のすべてを利用できます。

## 用意するもの

- **Rokid AI Glasses RV101**
- **最初のインストールに使うMacまたはWindows 10/11のPC**
- **Rokidの開発用5ピンケーブル**
  充電用ケーブルとは別の開発用ケーブルです。
- **スマートフォンのRokidアプリで、開発者モード（ADB）を有効にしておくこと**

開発用5ピンケーブルをつなぐだけではADBは有効になりません。RokidをPCへつなぐ前に、スマートフォンのRokidアプリ側で開発者モード（ADB）を有効にしてください。

## 最初のインストール

### 1. アプリ一式をダウンロードする

[最新版ZIPをダウンロード](https://github.com/ksuzukigh/rokid-zoom-in-camera/releases/latest/download/Rokid-ZOOM-IN-CAMERA.zip)し、ダウンロードしたZIPファイルを展開します。

### 2. RokidをPCへつなぐ

1. Rokidの電源を入れます。
2. 開発用5ピンケーブルでMacまたはWindows PCへつなぎます。
3. RokidにUSB接続の確認が出た場合は許可します。

### 3. インストーラーを開く

- **Mac**：`Rokidへアプリを入れる.command`をダブルクリックします。
- **Windows**：`install-rokid-zoom-in-camera.cmd`をダブルクリックします。

画面の案内に従い、「インストールが完了しました」と表示されたら準備完了です。必要な接続ソフトがPCにない場合は、Google公式のAndroid Platform-Toolsを自動で準備します。HomebrewやAndroid Studioの事前導入は不要です。

<details>
<summary>Macに止められた場合</summary>

1. 警告画面では「ゴミ箱に入れる」を押さず、「完了」を押します。
2. Macの「システム設定」を開きます。
3. 「プライバシーとセキュリティ」を開き、一番下までスクロールします。
4. `Rokidへアプリを入れる.command`の「このまま開く」を押します。
5. 確認画面でもう一度「このまま開く」を押し、Macのログインパスワードを入力します。

</details>

<details>
<summary>Windowsに止められた場合</summary>

1. 「WindowsによってPCが保護されました」と表示されたら「詳細情報」を押します。
2. ファイル名が`install-rokid-zoom-in-camera.cmd`であることを確認します。
3. 「実行」を押します。

</details>

## 困ったとき

### Rokidがインストーラーに見つからない

- スマートフォンのRokidアプリで開発者モード（ADB）が有効か確認します。
- 充電用ではなく、開発用5ピンケーブルを使っているか確認します。
- RokidにUSB接続の確認が表示されている場合は許可します。
- ほかのAndroid端末をPCへつないでいる場合は、いったん外してからやり直します。

### カメラ映像が表示されない

Rokid純正「カメラ」など、カメラを使う別のアプリを閉じてからRokid ZOOM IN CAMERAを開き直します。Rokidのカメラは複数のアプリから同時には使えません。

### 録画中に倍率を変えられない

正常な動作です。動画の途中で画角が変わらないよう、録画中は倍率を固定します。一度録画を終了し、倍率を選び直してから次の録画を始めてください。

### Hi Rokidへ取り込めない

- RokidとスマートフォンがHi Rokidで接続されているか確認します。
- Hi RokidのGallery（アルバム）をいったん閉じ、開き直します。
- 取り込みが完了するまでは、Rokid側の写真や動画を削除しないでください。

## 安全性とプライバシー

- インターネット通信やクラウドへの送信を行いません。
- マイク、位置情報、連絡先、利用状況の収集を行いません。
- 写真と動画は、Hi Rokidへ取り込むまでRokid本体に保存されます。
- アプリ使用中だけ、Rokid標準カメラとの衝突を防ぐため、カメラボタンの標準動作を一時的に停止します。
- アプリの終了、異常停止、Rokidの再起動時には、カメラボタンの標準設定へ戻します。

詳しくは[プライバシー](PRIVACY.md)を参照してください。

## 注意

- Rokid AI Glasses RV101 / YodaOS専用です。
- ズームは中央を切り出すデジタルズームです。倍率を上げるほど細部は粗くなります。
- 動画は約1分90MBを目安に保存容量を使います。被写体や撮影時間により前後します。
- 長時間の録画は電池を大きく消費し、本体が熱くなる場合があります。
- 周囲の安全を確認し、歩行中や運転中は操作しないでください。

## 削除するには

1. スマートフォンでRokidアプリを開きます。
2. 「ホーム」→「ツールボックス」→「メガネのアプリ管理」の順に開きます。
3. 「Rokid ZOOM IN CAMERA」の右側にある丸い「－」ボタンを押し、画面の案内に従います。

アプリを削除しても、撮影済みの写真と動画は消えません。必要なものは、削除前にHi Rokidへ取り込んでください。
